Meter Config Exporter

เครื่องมือจัดการข้อมูลมิเตอร์และส่งออกไฟล์ .txt (6 แบรนด์อัตโนมัติ)

เพิ่มข้อมูลมิเตอร์

ใส่อักขระ 12 หลัก ระบบเติม `:` ให้อัตโนมัติ

แบรนด์และรหัสผ่านที่จะขยายอัตโนมัติ:
TTC: 00454712
TC KAIFA: 00000001
IPG: 00000000
PRECISE: 00000001
EMAX: 00454712
KY: 00000000

รายการมิเตอร์และรหัสผ่านย่อย

แสดงชื่อแบรนด์นำหน้ารหัสเครื่องวัดโดยอัตโนมัติโดยไม่มีเลขลำดับ

#Name,Bluetooth Mac,Password,Meter Type(1 or 3),Descriptor

ยังไม่มีข้อมูลมิเตอร์ในระบบ

กรอกข้อมูล NAME และ BLUETOOTH MAC ด้านซ้ายเพื่อเริ่มบันทึก

NAME (Brand + Code) BLUETOOTH MAC PASSWORD TYPE DESCRIPTOR ลบ
รวมทั้งหมด 0 มิเตอร์ (0 แถวในไฟล์ .txt)

ตัวอย่างเนื้อหาไฟล์ .txt

รูปแบบไฟล์เมื่อทำการดาวน์โหลด

Header: #Name,Bluetooth Mac,Password,Meter Type(1 or 3),Descriptor
